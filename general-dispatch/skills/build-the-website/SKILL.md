# Build the website

Read the MCP resource `skill://build-a-site` and follow it. The short version: `get_site` gives the exact widget snippet, lead-form endpoint and click-to-call to paste in; deploy in parts (`deploy_site`: home page, stylesheet and 404 first, then service pages a few at a time, then contact, robots.txt and sitemap.xml); show the preview only when no warning says a link points at a missing page. `publish_site` needs the business to be live, so on the free plan the preview is the deliverable.
